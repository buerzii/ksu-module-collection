## DirBridge

- 作者：liebig（GitHub：Liebig773）
- 原项目：https://github.com/Liebig773/DirBridge
- 上游下载：https://github.com/Liebig773/DirBridge/releases
- 发现来源：[酷安原帖](https://www.coolapk.com/feed/74550945)
- 归档版本：v0.1.3（versionCode 103）
- **本仓库安装包：[DirBridge-v0.1.3.zip](./DirBridge-v0.1.3.zip)**，已提交到本仓库，不依赖上游文件继续存在。

根据作者说明，使用只读 bind mount，将 Telegram、迅雷等应用的下载目录映射到播放器可访问的共享存储入口，不复制、移动或转码视频。支持多目录、中文 WebUI 和开机自动应用。

要求 Root、KernelSU / KernelSU Next，以及标准 BusyBox、WebUI 接口。安装器最低要求 Android 10（API 29），不等于所有 Android 10 及以上设备均已验证。目前仅支持主用户内部共享存储；Magisk、APatch 不在作者当前安装器支持范围内。以原项目说明为准。

仅核对了用户提供 ZIP 的模块元数据、许可证及文件列表；未安装测试，未做完整代码安全审计。
